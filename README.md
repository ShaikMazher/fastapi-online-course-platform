# FastAPI Online Course Platform Backend 🎓

This is a fully functional REST API backend for an Online Course Platform, built using FastAPI as part of the Innomatics Research Labs Advanced Generative AI Internship.

## Features Implemented
* GET APIs & Summary Endpoints
* POST APIs with strict Pydantic validation
* Helper functions for business logic (discount calculations, early-bird pricing)
* Full CRUD operations (Create, Read, Update, Delete)
* Multi-step workflows (Wishlist addition and Bulk Checkout)
* Advanced Search, Sorting, and Pagination logic
* Tested entirely via Swagger UI
